# Path Home: Structural Reentry Assistance — Asset pack

**Working brand palette:** deep navy #08253D, teal #008978, warm gold #EDB64F, cream #FFF5DC.

- `path_home_horizontal_logo.png` — master horizontal wordmark with mission line.
- `path_home_app_icon_1024.png` — launch icon artwork without sensitive/criminal-justice imagery.
- `PathHome.ico` — multiresolution Windows icon.
- `google_play_icon_512.png` — app-store upload artwork.
- `tab_icons/` — twelve original line-style vector icons (SVG + PNG) with normal, selected and dark versions.
- Android `mipmap-*` and adaptive launcher icons are installed in the native Android project.
- Desktop icon and navigation bitmap assets are installed in the native Windows project.

The icon depicts an open door, sun, and path home. Avoid portraying returning citizens through prison bars or handcuffs. Typography is DejaVu Sans in the current mockup and can be replaced when final branding is approved. No paid font is bundled.
