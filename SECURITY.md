# Security and user privacy

Path Home: Structural Reentry Assistance is intended to keep personal release plans on the user's own device. Never file an issue with screenshots or exports containing names, addresses, parole records, appointment locations, supervision dates, or other personal information.

**Current status: development / not cleared for production.** Android has not been compiled and tested on a device in this environment; Windows has not been smoke tested on Windows and has not undergone independent penetration testing. No third-party legal review has certified comprehensive 50-state coverage.

Report suspected vulnerabilities privately to the publisher through an independently verified company contact channel. Do not post exploitation details or personal information in public issues.

Stay on Track is optional, local-only, and is not a parole compliance monitor.
